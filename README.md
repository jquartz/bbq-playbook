# Pitmaster's Playbook — Professional Static Site

A mobile-first BBQ operations manual for the Sunday 30 August event, targeting a 3:00 PM buffet.

## Pages
- `index.html` — event overview
- `run-sheet.html` — Friday-to-Sunday working run sheet
- `recipes.html` — meats, rubs, sides and bone marrow
- `shopping.html` — consolidated shopping/equipment checklist
- `fire.html` — overnight fire management and recovery guide
- `service.html` — Sunday command centre and appliance map

## Features
- Responsive design
- Print-friendly pages
- Persistent checklist state using browser `localStorage`
- Built-in Sunday timers
- GitHub Pages-ready; no build step
- `.nojekyll` included

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Cooking note
Times are planning ranges. Bark, tenderness and safe food handling override the clock.
Use reliable thermometers, cool cooked food promptly if not holding hot, refrigerate safely and reheat thoroughly.
